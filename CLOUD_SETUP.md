# DragonFly Lotus V7 — Connected Intelligence Setup

1. In Supabase SQL Editor, run `SUPABASE_SETUP.sql`.
2. In Authentication → URL Configuration, set the Site URL and Redirect URL to:
   `https://rendahobbsmarsh-bit.github.io/dragonfly-lotus-command-center/`
3. In DragonFly Lotus → Cloud, paste the Project URL and Publishable key.
4. Save Cloud Configuration.
5. Enter your email and a password of at least 8 characters.
6. Click Create Account. If email confirmation is on, confirm it, then Sign In.
7. Use the same email and password on Mac, iPhone, and iPad.

Use only the publishable key. Never paste a secret or service-role key into the app.
