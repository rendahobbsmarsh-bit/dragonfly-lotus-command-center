# DragonFly Lotus V7.0 — Connected Intelligence

Adds Create Account, email/password Sign In, Sign Out, Forgot Password, persistent Supabase sessions, cloud mirroring, offline queueing, safety backup, and Connected Intelligence.

## Install
```bash
unzip -o DragonFly_Lotus_v7_0_Connected_Intelligence.zip
git add .
git commit -m "DragonFly Lotus V7.0 - Connected Intelligence"
git push
```

V7 is active when the header says V7.0 and the Cloud workspace shows Create Account and Sign In.
