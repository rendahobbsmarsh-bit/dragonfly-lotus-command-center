# DragonFly Lotus V8.0 — Zero Configuration Devices

V8 removes the manual cloud-configuration step from new devices.

## New-device experience

1. Open DragonFly Lotus.
2. Open Cloud.
3. Enter the same email and password.
4. Select Sign In.

The browser-safe Supabase Project URL and publishable key are already included in the app. The connection fields remain under **Developer Setup** only for troubleshooting.

## Install

```bash
unzip -o DragonFly_Lotus_v8_0_Zero_Configuration_Devices.zip
git add .
git commit -m "DragonFly Lotus V8.0 - Zero configuration devices"
git push
```
